Adds the Codecogs WYSIWYG LaTex equation popup editor to Wordpress TinyMCE editor.

== Description ==

The official CodeCogs plugin for Tiny MCE that makes writing LaTeX equation easy. It converts latex code into graphical images to providing beautiful equations directly within your work.

A new "fx" botton will appear within the wordpress TinyMCE editor. Click this to open the Equation Editor dialog into which you can form your equations. Click ok to enter the final equation into your document. 

Credits to
  - https://www.wpbeginner.com/wp-tutorials/how-to-create-a-wordpress-tinymce-plugin/ 

== Installation ==

1. Upload to the `/wp-content/plugins/` directory
2. Activate the plugin through the 'Plugins' menu in WordPress
3. Find the "fx" button on you wordpress TinyMCE editor
